    cd C:\Users\nacho\Desktop\codigo\scripts
    python run_all_experiments.py

8. PIPELINE PHASES
================================================================================

The notebook (main.ipynb) executes the following phases in order:

Phase 0 — Setup
    - Load config.yaml via config_loader.
    - Validate configuration schema (config_validator).
    - Load and preprocess market data (data_loader).
    - Initialize logger (overwrite mode, one .txt per module).
    - Initialize passport orchestrator (data lineage tracking).

Phase 1 — Classical Formulation
    - Compute initial CVaR and VaR for equal-weight portfolio.
    - Compute portfolio metrics (Sharpe, Sortino, max drawdown).
    - Build noise model if noise simulation is enabled.
    - Prepare data structures for quantum estimation.

Phase 2 — Quantum-Hybrid Optimization
    - Construct QAE circuits (tail probability, conditional expectation).
    - Estimate CVaR via Quantum Amplitude Estimation (IQAE and/or Woerner).
    - Run hybrid optimizer: Adam-based subgradient descent using
      quantum-estimated gradients.
    - Apply ZNE error mitigation if enabled.
    - Compute EVaR (Entropic Value at Risk).
    - Perform error propagation analysis.
    - Compute Euler risk contributions.

Phase 3 — Validation and Benchmarking
    - Run classical benchmarks (SLSQP, COBYLA, classical subgradient).
    - Compare QAE methods (IQAE vs Woerner accuracy and efficiency).
    - Out-of-sample validation (train/test split at oos_split_date).
    - Aggregate all metrics into comprehensive JSON output.
    - Export convergence CSV and optimal weights CSV.

9. CONFIGURATION REFERENCE
================================================================================

Key parameters in config.yaml and their effects:

Global:
    alpha                   CVaR confidence level (default: 0.05)
    random_seed             Reproducibility seed (default: 42)
    constraints.max_weight  Maximum weight per asset (default: 0.30)
    constraints.long_only   Long-only constraint (default: true)

Data:
    tickers                 List of ticker symbols
    start_date / end_date   Date range for market data
    oos_split_date          Train/test split date for OOS validation
    oos_enabled             Enable out-of-sample validation

Phase 2 — QAE:
    qae.epsilon             QAE precision (lower = more queries, higher
                            accuracy). 0.005 is standard, 0.002 is high
                            precision, 0.01 is fast/coarse.
    qae.num_distribution_qubits   Qubits for return distribution encoding
                                  (4 = 16 bins, 3 = 8 bins fast mode).
    qae.use_iqae            Enable IQAE estimator (default: true).
    qae.use_woerner         Enable Woerner direct QAE (slower but exact).

Phase 2 — Optimizer:
    optimizer.type          Optimizer type (default: adam).
    optimizer.max_iterations  Maximum iterations (default: 30).
    optimizer.learning_rate   Initial learning rate (default: 0.05).
    optimizer.convergence_threshold  Stopping criterion (default: 1e-5).
    optimizer.patience        Early stopping patience (default: 12).

Phase 2 — Noise and ZNE:
    backend.use_noise       Enable hardware noise simulation.
    noise_params.single_qubit_gate_error   1Q gate error rate.
    noise_params.two_qubit_gate_error      2Q gate error rate.
    zne.enabled             Enable Zero Noise Extrapolation.
    zne.scale_factors       Noise amplification factors (e.g., [1,3,5]).
    zne.extrapolation       Extrapolation method (e.g., polynomial).

Phase 2 — Backend:
    backend.type            Simulator type (aer_simulator).
    backend.shots           Number of measurement shots (default: 1024).
    backend.optimization_level  Transpiler optimization (0=none, 1=light).

12. TROUBLESHOOTING
================================================================================

Error: "No module named qiskit"
    -> Verify the eTFM environment is activated and the correct
       Jupyter kernel is selected.

Error: "AlgorithmError" in Woerner QAE
    -> Woerner requires StatevectorSampler (ideal, no noise).
       Ensure noise_model_config is None or use_woerner is disabled
       when noise simulation is active.
       See qae_circuits.py docstring (lines 14-19).

Error: "The job was not completed successfully" in IQAE
    -> IQAE with noise requires TranspilingAerSamplerV2 (a wrapper
       that transpiles circuits to basic gates before sending to Aer).
       Verify qiskit-aer is installed.
       See qae_circuits.py, class TranspilingAerSamplerV2.

Error: "PassportOrchestrator has no attribute 'compute_hash'"
    -> The noisemodels.py file has not been updated to the cleaned
       version. Replace src\phase_2\noisemodels.py with the latest
       cleaned module (480 lines, not the 1204-line original).

Error: CSV file not found during data loading
    -> The notebook resolves paths relative to its own directory.
       Ensure returns_sp500_100.csv exists at data\returns_sp500_100.csv.
       The notebook includes a fallback that resolves from project root.

Slow execution (>1h per configuration)
    -> Reduce epsilon to 0.01 (fewer IQAE queries).
    -> Reduce num_distribution_qubits to 3 (8 bins instead of 16).
    -> Reduce shots to 1024.
    -> Disable Woerner (use_woerner: false) if only IQAE is needed.
    -> Disable out-of-sample validation (oos_enabled: false).
    -> Disable benchmarking in the notebook configuration.

Frontend not loading data
    -> Ensure JSON files are in frontend\data\ (not frontend\).
    -> The app searches for tfm_comprehensive_metrics_*.json in data\.
